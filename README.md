# Type Default Audit

**What do frontier AI models recommend when designers ask for type?**

Across 1,890 controlled calls to Claude, ChatGPT and Gemini, the models named 1,029 typefaces, and forty of them carried half the answers. The brief set is balanced by design rather than representative of typical practice (see [Limitations](#limitations)).

**Read the full write-up:** [nicoleminoza.com/type-default-audit](https://nicoleminoza.com/type-default-audit)

## Why it exists

More designers now start a font search by asking an AI model. If a small set of families dominates those answers, that shapes what gets used, licensed and noticed. This audit measures how concentrated the recommendations are, so there is a baseline to evaluate AI font-discovery systems against.

## Findings

- **Concentration:** 1,029 typefaces named, forty of which carried half the answers. 228 of the 1,029 are in the Google Fonts catalog.
- **Catalog constraint:** restricting the models to Google Fonts widened their picks by 29.1 percent. Latin-only briefs, Claude and ChatGPT only.
- **Controls:** a placebo constraint of matched form did not widen the set, which is inconsistent with constraint satisfaction as the explanation.

## Method

- **Models:** `claude-opus-4-5-20251101`, `gpt-5.5-2026-04-23`, `gemini-3.1-pro-preview`
- **Calls:** 1,890. 210 briefs, three models, three repetitions, five recommendations each
- **Design:** briefs tagged on five dimensions with balanced marginals. See [`audit/BRIEF_SET.md`](audit/BRIEF_SET.md)
- **Preregistration:** [`preregistration.md`](preregistration.md), result in [`placebo_result.md`](placebo_result.md)

Every metric is defined in [`audit/METRICS_GUIDE.md`](audit/METRICS_GUIDE.md). Every published number is traced to its source in [`audit/RECONCILIATION.md`](audit/RECONCILIATION.md).

## What's in this repo

**`src/`: the pipeline**
- `config.py`: paths and `.env` loading
- `providers.py`: API clients for the three models
- `fetch_catalog.py`: fetches the Google Fonts catalog, which is the reference corpus rather than a constraint
- `build_brief_grid.py`: assigns the dimension tags
- `build_briefs.py`: assembles `briefs.json` from the grid and the authored texts
- `brief_texts/`: the brief text, in six batches
- `run_recommendations.py`: sends every brief to every model and records the responses
- `normalize.py`: resolves returned font names to catalog families
- `metrics.py`: concentration and coverage metrics, per condition
- `sample_adequacy.py`: checks each slice is large enough for a stable answer

**`audit/`: the outputs**
- `summary_open.json`, `metrics_open.csv`: results for the open condition
- `normalization_decisions.csv`: every name-matching decision, for review
- `METRICS_GUIDE.md`, `BRIEF_SET.md`, `RECONCILIATION.md`, `README.md`: the documentation above

`briefs.json` is the full brief set. `index.html` is the write-up. `release/` is the public data release. `probe/` is scaffolding for a separate manual study that has not been run, and holds no results.

## Reproduce

Python 3, no third-party packages. Keys go in `.env` at the repo root:

```
GOOGLE_FONTS_API_KEY=
ANTHROPIC_API_KEY=
OPENAI_API_KEY=
GEMINI_API_KEY=
```

`GOOGLE_FONTS_API_KEY` is required for the catalog fetch. Each model runs only if its key is set.

```bash
python src/fetch_catalog.py
python src/build_brief_grid.py
python src/build_briefs.py
python src/run_recommendations.py
python src/normalize.py
python src/metrics.py --condition open
python src/sample_adequacy.py
```

Order matters: `build_brief_grid.py` writes the grid that `build_briefs.py` reads.

Only `run_recommendations.py` costs money. The 1,890 calls took 8.7 hours of summed latency and consumed roughly 188,000 input and 936,000 output tokens, plus 1.3 million reasoning tokens on Gemini.

## Limitations

The brief set is balanced, not representative. 80 percent of briefs demand a non-Latin script, so pooled figures need reweighting before they describe typical practice.

Specificity is word count, so any specificity effect is also a prompt-length effect. The briefs were written by Claude, one of the models under test.

The study measures concentration, not recommendation quality. Catalog reach is not a measure of what a model holds. The restricted condition is complete for Claude and ChatGPT only, so every between-condition comparison covers two models.
